## The entry

> My microwave beeps when the food is done, then beeps again every minute until I apologise for ignoring it.

106 characters, one line, one gadget: the microwave as a passive-aggressive nag — not broken, not slow, just unwilling to let an ignored beep go.

## How it works

`main.ts` (Node 22, stdlib only) writes the fixed line to `/output/entry.txt` — 106 characters, inside the 1–200 character gate. Deterministic, no network, no secrets, no randomness.

Run locally:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
